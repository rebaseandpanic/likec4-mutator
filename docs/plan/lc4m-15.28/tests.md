# Test plan: Read and edit the LikeC4 deployment model

**Date** 2026-10-12 · **Requirements**: `docs/plan/lc4m-15.28/spec.md` · **Plan**: `docs/plan/lc4m-15.28/plan.md`

All rows are vitest unit tests (`npm test`). The project has no other test level. Every row runs in `wave`.

The expected values come from three places. The first is LikeC4 1.59.4 itself: `buildLikeC4Model` (`$data` layer and getters), the new `linkedReferences`, and `validateLikeC4` / `expectValidLikeC4`. The second is the literal outputs recorded in spikes 02–07. The third is the spec text. No expected value comes from the library's own output. "Byte-identical" means `serialize()` before equals after, and a read of the addressed entity also returns its earlier value (INV-2).
